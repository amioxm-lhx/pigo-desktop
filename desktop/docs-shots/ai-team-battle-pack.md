# 作战包：今天就把第一单打出来

这份东西是给我自己看的操作手册，不是产品介绍。产品介绍在 `ai-team-promo.md`。

---

## 0. 先说一句可能不爱听的话

**第一单不会来自软文流量。**

一个人做产品，第一单几乎从来不是"我写了一篇文章，有人看到，然后下单了"。真实发生的是：**我看见你在问这个 → 我正好在做这个 → 我给你看 → 你信了 → 你付钱。** 中间没有"内容自然传播"这一步，因为它对 0 粉丝的人不存在。

所以今天只做三件事：

1. 找到**正在公开问这个问题**的人（不是潜在用户，是正在问的人）。
2. 把他的问题**答透**，答到他自己没法反驳。
3. 让他**私信你**。

这套系统能替你干完 1 和 2 的准备工作，第 3 步靠你点一下发布。

## 2. 今天的操作顺序（约 100 分钟，其中 85 分钟是等机器干）

### 第 0 步：确认知乎登录态（1 分钟）

`AI 团队 → 目标网站 → 知乎`，看是不是"已登录"。显示"未登录"就点**重新登录**，手机扫码。

### 第 1 步：跑一轮侦察员（10~20 分钟，你不用管）

`AI 团队 → 员工 → 侦察员 → 立即运行一次`

它会按关键词清单（一个人怎么推广自己的产品 / 独立开发 怎么找到早期用户 / 一人公司 怎么做营销 / …）去知乎搜，读搜索结果页，再读点进去的问题页和评论。

**它会自己把不合格的人丢掉**。三条硬闸缺一条就丢，交回来的每一个都是"这个人自己在问怎么获客"。

> 想只测一个页面：在 `目标网站` 的**采集入口**里填一个具体网址，关键词清单就作废，只读这一页。

### 第 2 步：让线索主管分级派活（5 分钟）

`商机池` 顶上就是它的判断。它会把线索分级、把该发的活派给笔杆子和地推员，**不需要你批**，每天的件数有上限。

### 第 3 步：定稿（10 分钟）

今日页（`我的应用 → 今日`）。笔杆子会一次交好几版（A/B/C 版，区别在开头第一句），每一版是一行，点**定稿批准**定完。想先读一遍就点**看正文**，正文就地展开、就地能改；要翻全部版本再点**改字**进内容工厂。

定完之后同一行会变成"发布"行，点**发布**——状态变成**待发布**，稿子进发布队列，地址这一栏从头到尾不问你。发出去之后地址回填到内容工厂的「待发布」列（谁发谁回填：你自己发就点「标记已投放」把链接贴上）。

### 第 4 步：发布 —— 你按一下，地址不用填（1 分钟）

"要不要说"是你的事，"填什么地址"不是。你在今日页点一下**发布**，稿子变成**待发布**（`queued`），进发布队列，界面不再问你要链接。全程你只按两下，一次地址都不用填。

- **想自己发也留着口子**：点**看正文** → 点**复制正文** → 点**打开原帖** → 在知乎里粘上去 → 发送 → 到内容工厂的「待发布」列点**标记已投放**把地址贴上。
- **它打字、你按一次**（需该站点已登录，**目前只接通知乎**）：`node apps/desktop/test/manual/staff-publish-live.mjs --content <稿子 id 前 8 位> --url <目标页面>`。它借用采集用的那个登录窗口，把稿子打进站点自己的评论框，再按站点自己的发布按钮；发现编辑框里不是你这条稿子就拒绝点。加 `--dry` 只打字不发。
- **还没接上的那一步**：地推员自己排期、自己按站点按钮发出去。它现在只备现场版，不会开火。

自己动手发的那条，发完回卡片点**标记已投放**，把链接贴进去，回音巡检同样从那一刻开始跑。

### 第 5 步：回音巡检（不用你干）

贴了链接就不用管了：系统每 15 分钟自己回去读一遍那条内容，谁回了、几个赞，直接写进卡片；有人在评论区回你，
它自己在**商机池**建一张标了「自动采集」的卡。内容工厂顶上那条**回音巡检**就是它的进度——想看就点**立刻巡检**。

**它读不到的一个数**：知乎的阅读数只在作者创作中心里，公开页面上没有。所以卡片上的**手工回填**留着填浏览数，
回复数不用你填。

### 第 6 步：有人私信你 → 记一条回音

`商机池 → 记一条回音`：把对方原话抄进去，贴上对话链接。

**这一步是最容易漏的，也是最值钱的。** 系统不会自己知道有人私信你了。不记，接线员和跟单员就没有活干，整条链路就停在这里——上一轮九个人忙了一整天，最后自己的结论是「**零发出、零回应、无一条约成**」。

### 第 7 步：接线 → 报价 → 收钱

把回音那张卡在 `商机池` 里往后拖：`有回应 → 洽谈中 → 已成交`。**拖到"已成交"时会让你写一句成交记录**（买了什么、多少钱）——战报的成交数就按这个算。

### 第 8 步：交付 + 要一句见证

交付完，去要一句话。一个真实客户的真实原话，比一百篇软文有用。

## 3. 话术（可以直接抄）

报价和硬边界在 `弹药库` 里，所有员工开工前都会读，改一处全场跟着改。

### 3.1 自己发回答：四段，一段都不能少

1. **直接回答**。给一样他今天就能用的东西——一个动作、一张表、一个标记。不是方法论。
2. **给真实数字**。九个员工、每个一把 key、共享记忆、本地 SQLite、中层每天最多派 5 件活。
3. **我在做什么 + 怎么找我**。一句话说清，结尾"私信我"。
4. **问一个只有他能答的问题**。这是钩子，没有这一句就没有回复。

### 3.2 别人的评论区留言：三段，不超过四句

唯一目标是**让他点开你的主页**。不提产品名、不放外链、不谈价格。

### 3.3 一条可以照抄的回答（换成你的数字）

> 早期用户不是"找"来的，是"你在他们已经在的地方把话说清楚了"来的。所以别做宣发，做三件事：
>
> 1. 列出你的用户一定会问的 10 个问题——不是你产品的功能，是他自己的问题。
> 2. 搜这 10 个问题，每个问题挑一条你能答得比别人具体的，只答那一条。
> 3. 在最后一行留一个只有他能回答的问题。
>
> 我自己就是这么干的。因为我一个人实在干不完，干脆把这件事拆成了九个员工：每个员工配自己的一把 API key、自己选的模型、自己的排期；员工之间共享一份记忆，上一轮抓回来的原话，下一轮所有人开工前都读得到；所有数据落在本机 SQLite，不上传服务器；中层不用请示我就能派活，但有每日上限。装在我自己的 Windows 上，关了就停，不是云服务。
>
> 你现在的获客动作是哪几个、每天花多久？

### 3.4 有人私信了：只问三件事

- **你现在卡在哪一步？**（让他说，别自己猜）
- **这件事你自己能拍板吗？**（不能拍板的不是客户，是传话的人）
- **你打算什么时候开始？**（没有时间点的都是"以后再说"）

### 3.5 报价

> 早鸟买断 ¥1980，前 50 名；之后 ¥2980。
> 先演示后付款：我拿十分钟给你看它真能干活，你觉得行再谈钱。

**不还价，不搞"原价 9980 现价 2980"。** 价格就是价格。

### 3.6 收尾

> 这一轮先这样。你用一周，一周后跟我说一句实话：哪件事它真替你干了、哪件事它反而添乱。我按你说的改。

## 4. 数字：多少人看到才够一单

一个人做产品，真实的转化大概是这样：

| 阶段 | 数量 | 说明 |
| --- | --- | --- |
| 认真留言 / 回答 | 20 条 | 一条 5 分钟，约 2 小时 |
| 点开你主页 | 3 ~ 8 人 | 留言写得好就有这个数 |
| 私信你 | 1 ~ 3 人 | 回答里有"只有他能答的问题"才有回复 |
| 成交 | 1 单 | |

**结论：今天不需要 20 条，需要 3 条答得极好的。** 与其广撒网，不如挑 3 个你自己都觉得"这个人真的在痛"的问题，把回答写成能直接当交付物的东西。

## 5. 系统不做什么（别对外吹）

1. **不替你发布**。成稿和目标位置它准备好，最后一下由你按；`staff-publish-live.mjs` 只是替你把字打进站点自己的框里，按按钮的仍然是你，而且只在有登录态的知乎。
2. **不承诺效果**。不保证曝光、不保证涨粉、不保证成交。
3. **不是云服务**。装在你自己电脑上，应用关了就停。准确说法是"开着机就不用管"，不是"永不下线"。
4. **站点适配只做了知乎**。掘金 / V2EX / B站 / 公众号 / 视频号 还在"尚未接入"，要各扫码登录一次才能采。
5. **中层派活不审批**，只限次数（每人每天 5 件），配额用完了剩下的排队，过期的作废。
6. **回音只读得到公开页面**。我们投出去的内容和它下面那串评论会自动读回来（默认 15 分钟一轮）；私信、微信、邮件读不到，知乎的浏览数也只有作者在创作中心看得到。所以浏览数还是手填，私信还是手记。

## 6. 出问题先看哪里

| 症状 | 先看 |
| --- | --- |
| 侦察员带回来的全是废话 | `目标网站` 里的关键词清单——写的是"你想蹲的问题"，不是"你的产品名" |
| 笔杆子写的像广告 | `弹药库` 里的 `outreach/playbook`，那份话术是全员口径 |
| 内容主编说"没有效果数据" | 去 `内容工厂` 给已投放的稿子**回填数据** |
| 中层一整天没派活 | `AI 团队 → 运行日志` 看它那一轮读了什么，缺什么下次补什么 |
| 员工说的话前后矛盾 | `弹药库` 里标了"存在分歧"的条目——那是两条内容不同的记忆，老板得裁一条 |
